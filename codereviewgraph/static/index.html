State Machine Logic

People step in only when it matters.

Deterministic rules execute instantly; human reviewers are engaged only at configured risk gates.

01

Syntax & Triage

Deconstructs the Python abstract syntax tree (AST) into isolated functions, classes, and import statements without executing untrusted code.

02

Dual-Agent Inspection

Two specialized agents run in parallel: Security Auditor flags injection vulnerabilities and credentials; Quality Auditor inspects complexity and style.

03

Reflection & Remediation

The Reflection Critic filters false positives, calculates severity scores, and routes severe flaws to an automated patch generator for safe diffing.
